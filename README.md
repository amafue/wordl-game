# Wordle Practice Game

A simple Wordle-inspired game built with HTML, CSS, and JavaScript.

## Features
- 6 rows with 5 letter inputs each.
- Automatic movement between input boxes.
- Backspace to delete letters.
- Press Enter to check a guess.
- Green, yellow, and grey feedback for letters.
- A keyboard that tracks used letters.

## Technologies
- HTML
- CSS
- JavaScript

## Status
This is an unfinished practice project. Win and loss messages have not been implemented, and some game logic is still incomplete.

## Purpose
The goal was to practice DOM manipulation, event listeners, loops, conditions, and CSS layouts.
